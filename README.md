QA Automation Project – SullenClothing

Note: The target website has been updated since the project was developed, so some tests may require adjustments to run as originally intended.

 Presentation:
This project is a simple UI automation framework built for learning and practicing QA Automation concepts.  
It tests navigation and category pages on the SullenClothing website using Selenium and Pytest.

The project is structured using the Page Object Model (POM) to improve maintainability and scalability.


Tools used:
- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)


 Project Structure:
/pages – Page Object classes (UI locators and actions)  
/tests – Test cases written with Pytest  
conftest.py – WebDriver setup and teardown  


 Contents:
- UI automation testing using Selenium
- Page Object Model design pattern
- Explicit waits (WebDriverWait) for stability
- Basic navigation testing between product categories
- Separation between test logic and page logic


What I did:
- I built a basic automation framework
- I used Selenium WebDriver for UI testing
- I implemented Page Object Model (POM)
- I wrote stable tests using explicit waits
- I structured a Python testing project
